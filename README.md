# 1次関数のグラフマスター

中学校数学の一次関数について、傾きと y 切片からグラフをかく練習をするWebアプリです。

## データと通信

- 学習履歴（実施日時・得点・満点）と最高点は、この端末のブラウザの `localStorage` にだけ保存されます。スタート画面の「リセット」で削除できます。
- 「まちがい直し（復習モード）」で得た点数は、学習履歴にも最高スコアにも保存されません。出題数が通常のセッションと異なるため、記録としては区別しています。
- 氏名、メールアドレス、学校名などの個人情報は入力・収集しません。
- アプリ本体は学習結果を外部へ送信しません。
- 数式表示・フォント・紙吹雪演出のため、ブラウザは Google Fonts（`fonts.googleapis.com`／`fonts.gstatic.com`）と jsDelivr（`cdn.jsdelivr.net`）に接続します。外部サービスの通信には各提供者の方針が適用されます。
- 利用する第三者ソフトウェアとフォントは [NOTICE.md](NOTICE.md) に記載しています。
